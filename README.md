> A plugin for [Voiden](https://github.com/VoidenHQ) — the developer-first API client.

# Markdown Preview

Live preview and rendering for Markdown files with full GitHub Flavored Markdown (GFM) support.

## Features

- Live markdown rendering in a read-only Voiden tab
- GitHub Flavored Markdown (GFM) support
- Tables with proper cell formatting
- Strikethrough text formatting
- Task lists and checkboxes
- Inline and reference-style links and images
- YAML frontmatter support
- Syntax highlighting for code blocks
- Automatic heading IDs
- Blockquotes, ordered and unordered lists
- Toggle preview panel visibility

## Usage

Open any `.md` or `.markdown` file and click the **Preview Markdown** button in the editor toolbar to open a live-rendered preview panel. The preview updates as you edit.
